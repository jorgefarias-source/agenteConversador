# Laboratório para Etapa 2

Objetivo: criar ambiente local sem WhatsApp, sem banco e sem escrita.

Requisitos de aceite do laboratório:
- Interface local em `127.0.0.1` (ou `localhost`) com rótulo LABORATÓRIO.
- Seleção de negócio para carregar FAQ por arquivo/configuração.
- Modo simulado com badge `SIMULADOR — NÃO É IA`.
- Exibir mensagens, resposta, fonte/versionamento, latência estimada e consumo.
- Botão para limpar conversa.
- Sem chamadas pagas e sem integração com WhatsApp.

Uso inicial:
1. `npm.cmd ci`
2. `npm.cmd run lab`
3. Abrir URL exibida no terminal.
4. Testar pergunta e limpa conversa.

Observação: esse prompt é o escopo mínimo para o primeiro ciclo técnico.
